Mini E-Commerce Shopping Cart

Project Overview

A responsive mini e-commerce web application developed using HTML, CSS, and JavaScript. Users can browse products, add items to their shopping cart, manage quantities, calculate totals, and preview checkout details.

Features

- Dynamic product catalog
- Add to Cart functionality
- Dynamic cart item count
- Increase and decrease product quantity
- Remove products from cart
- Automatic total price calculation
- Checkout preview modal
- Demo order confirmation
- Responsive user interface

Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- JavaScript Objects and Arrays

Key Concepts

- Dynamic item rendering
- Array methods
- Event handling
- Cart management
- Price calculations
- Modal interactions
- Responsive web design

How to Run

1. Download or clone this repository.
2. Open index.html in a web browser.
3. Browse products and add them to the cart.
4. Manage quantities and view the checkout preview.
